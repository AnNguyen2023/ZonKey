# Dictionaries


## M2 assets

M2 ships small project-curated exact-match lists in en-common.txt, it-common.txt, and products.txt. They were assembled for Zonkey from terms required by the project specification and corpus; no third-party word list was copied. Entries are UTF-8, one per line, compared case-insensitively, and original input casing is preserved. never-transform.txt inventories the deterministic pattern families implemented in Rust. See docs/dictionaries.md for maintenance rules.
M0 chưa chứa word list. M1/M2 sẽ thêm các nguồn đã kiểm tra license và provenance:
`en-common.txt`, `it-common.txt`, `products.txt`, `patterns.toml` và
`never-transform.txt`. Dictionary cá nhân không được commit.
